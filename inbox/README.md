# Mandu Inbox

Drop new learning material here as `.md` files through Obsidian.
Videos, tutorials, articles, documentation, course material, and personal notes all use the same entry point.
Any subject hcho studies is welcome; Mandu organizes knowledge by subject as material arrives.
The existing AI wiki remains the home for general AI knowledge, and other subject areas are added only when needed.
Include the original title, source link, author, and timestamps when available; missing details do not need to be invented.

After adding a file, run the existing `/ingest` skill.
If several files are pending, name the one to process.
Mandu preserves the supplied source, selects the appropriate knowledge destination, summarizes useful lessons, and connects relevant notes and projects.
Mandu gives a short review afterward and asks only about material ambiguities that prevent accurate filing.
Existing source folders remain intact.

Adding a file alone does not start background processing; `/ingest` is the trigger.
This README describes the workflow and is not a source to ingest.
