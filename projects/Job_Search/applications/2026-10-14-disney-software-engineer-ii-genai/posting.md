Job Summary:
We are looking for an AI Engineer to help build and support enterprise Generative AI applications. This role will contribute to our conversational AI platform for enabling natural language interaction with enterprise operational data.

The role focuses on hands on GenAI application engineering, including Python development, retrieval and grounding workflows, prompt design, conversational AI support, and backend service integration. It also includes direct exposure to production GenAI practices, including LLMOps across evaluation, observability, deployment support, agentic workflows, tool calling, MCP style integrations, and production troubleshooting.

The ideal candidate can build, debug, learn quickly, use AI developer tools effectively, and contribute to reliable production GenAI systems. Azure experience is a plus.

Responsibilities and Duties of the Role:
Technical Leadership & Expertise
- Build and maintain Python based GenAI application components
-  Connect conversational AI workflows with backend services, web applications, and internal tools
-  Implement retrieval and grounding workflows that support source backed AI responses
-  Develop prompt logic, response formatting, structured outputs, and validation patterns
-  Assist with document ingestion, semantic chunking, metadata handling, and retrieval testing
-  Support agentic workflows involving tool use, function calling, API actions, and multi step reasoning
-  Learn and contribute to MCP style integration patterns for connecting AI systems to tools, data, and enterprise services
-  Support LLMOps practices, including observability, logging, monitoring, evaluation, latency tracking, cost tracking, and production troubleshooting
-  Help create and maintain validation datasets, regression tests, and response quality review workflows
-  Assist with deployment support, environment configuration, and operational documentation
-  Use AI developer tools such as Cursor, Claude Code, or similar tools as part of the required engineering workflow to improve velocity, code understanding, testing, and documentation quality
-  Work with senior engineers to improve reliability, maintainability, and transparency of GenAI systems

Required Education, Experience/Skills/Training:
Basic Qualifications
- 3+ years of professional software development experience
- Strong Python development skills
-  Hands on experience or project work with GenAI applications or conversational AI systems
-  Familiarity with retrieval based GenAI patterns, grounding, embeddings, vector search, and prompt engineering
-  Experience integrating APIs and backend services
-  Hands on exposure to MCP, tool calling, function calling, or agentic integration patterns
-  Exposure to cloud application development in Azure, AWS, or GCP
-  Ability to read logs, investigate issues, and troubleshoot application behavior
-  Working knowledge of LLMOps concepts, including evaluation, observability, monitoring, deployment support, and production AI system reliability
-  Required use of AI assisted developer tools such as Cursor, Claude Code, or similar tools to support development velocity, documentation, code review preparation, and technical problem solving
- Bachelor's degree required

Preferred Qualifications
Frontend depth and platform experience
- Experience with Azure OpenAI, Azure AI Foundry, Azure Functions, Azure App Service, or Application Insights
-  Experience with Microsoft Teams bots or enterprise conversational interfaces
-  Familiarity with Snowflake Cortex, Cortex Analyst, semantic views, or natural language to SQL workflows
-  Experience with MongoDB, Atlas Vector Search, or graph databases
-  Experience testing AI responses against expected answers, source data, or user feedback
-  Exposure to CI/CD, Docker, telemetry, and deployment pipelines
-  Interest in secure enterprise AI patterns, grounding, access control, and responsible AI behavior
