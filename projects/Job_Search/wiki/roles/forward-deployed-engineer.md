# Forward Deployed Engineer (FDE)

## What it is
The customer-embedded builder. An FDE embeds directly with an enterprise customer and ships production AI/agent applications inside the customer's environment, then feeds patterns back to product and engineering.
Not traditional consulting: hands-on-keyboard, owns the technical win, ships code that goes live.
The single most common archetype in hcho's ingested postings (8 of 15), spanning frontier labs, eval/observability vendors, and YC startups.
Sits in the **AI builder** bucket, with a strong customer-facing overlay.

## Day-to-day
- Embed with strategic customers; run discovery, translate ambiguous business pain into shipped solutions.
- Co-architect and co-build production AI agents (multi-step workflows, orchestration, failure handling).
- Own the technical win in pre-sales: POCs, architecture reviews, guiding evaluations.
- Deliver artifacts: MCP servers, sub-agents, Agent Skills, integrations; sometimes on-prem/private-cloud deployment.
- Run workshops, trainings, and knowledge transfer; build long-term customer relationships.
- Travel to customer sites: consistently 25-40% across postings.

## Required qualifications and skills

Must-have (recurring across all 8):
- [[python]] - universal baseline; several also require [[typescript]] / JavaScript (Vercel is TS-primary).
- [[llm-application-development]] - production LLM apps beyond simple API calls.
- [[agent-orchestration]] - agent-based apps: multi-step workflows, orchestration, tool use, failure handling.
- [[customer-facing-delivery]] - the defining skill: embed with customers, run discovery, present, build trust, travel. This is what separates FDE from a pure builder role.

Common must / strong-plus:
- [[eval-pipeline-design]] - "guiding evaluations," "LLM evaluation, observability, guardrails" (LangChain, Anthropic, Cohere).
- [[rag-systems]] - client/server RAG apps (Cohere North, Closure).
- [[distributed-systems]] - resilient/secure systems, cloud (AWS/GCP/Azure), containers, K8s, IaC (Vercel v0, LangChain, Closure).
- [[nextjs-react]] - front-end/full-stack for the web-platform FDEs (Vercel).

Experience bar: typically 3-5 years, at least ~2 in a customer-facing technical role; "former technical founders encouraged" is near-universal. Bachelor's sufficient.

## Seniority and comp
Range across postings: ~$126K-$300K base/OTE, plus equity. Frontier labs top the band (Anthropic $200K-$300K); web-platform FDEs lower (Vercel $126K-$207K).

## hcho's fit and gap
**Fit: 3/5 - good technical match, real customer-facing gap.**

Strong:
- The technical core is squarely in reach: Python, production LLM/agent apps, RAG, and evals are all hcho strengths (Agentic RAG is a direct artifact).
- Several variants are accessible: "former technical founders encouraged," 3+ years, Bachelor's-fine, and Cohere's Prompt Specialist is explicitly 0-5 years.
- The eval-heavy pre-sales/technical-win framing rewards hcho's validation rigor.
- Location is no longer a blanket blocker on this archetype: Cohere's **Agentic Platform (West Coast)** variant (2026-07-13) is remote with Los Angeles among eligible locations, so an eval-centric Cohere FDE is now LA-local-eligible for hcho. [[cohere-fde-agentic-platform]]

Gaps:
- [[customer-facing-delivery]] is the defining skill and hcho's thinnest area: no enterprise customer-embedded or pre-sales track record, and the role is built around it.
- Sustained 25-40% travel is a lifestyle factor to weigh (watch-out, not a skill gap).
- [[typescript]] / [[nextjs-react]] gate the Vercel variants specifically.
- Two variants have hard clearance gates (Cohere Sovereign AI: Canadian Top Secret; Closure: CJIS) - likely non-starters for hcho.

## Path to close the gap
1. Reframe hcho's experience to the customer-facing bar: a decade of QA sign-off, cross-functional and vendor-facing work, plus solo-founder discovery/shipping = evidence of "high agency, ambiguity, stakeholder translation." Make this explicit in the resume and story.
2. Target the accessible variants first: Cohere Prompt Specialist (0-5 yrs, eval/prompt-centric - a strong fit for hcho's differentiator), LangChain Deployed Engineer (eval/observability is their nice-to-have and hcho's strength), Anthropic FDE (values evals + high agency).
3. Skip the clearance-gated variants (Cohere Sovereign AI, Closure) unless the situation changes.
4. If pursuing Vercel, close the [[typescript]]/[[nextjs-react]] gap; otherwise deprioritize the TS-primary FDEs.
