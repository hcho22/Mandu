# TypeScript

## What it is
TypeScript / JavaScript for full-stack and front-end AI product work.
Increasingly paired with Python in AI-builder job requirements; primary language for some employers.

## Why roles want it
Recurring across the batch. Vercel FDEs are TypeScript-primary (expert TS + Next.js required). Hex and LangChain want Python + JS/TS ("strong in one, open to both"). Cohere names Python/TypeScript together.

## How to acquire or demonstrate
Ship production TS/JS in a real codebase; for the web-platform roles, pair it with [[nextjs-react]].

## hcho's current level: learning
Evidence for: CreativeBridge is React Native + Expo (JS/TS ecosystem); Agentic RAG's frontend is React/Vite. So hcho has real JS/React exposure.
Evidence against: hcho is Python-primary; "expert TypeScript" (Vercel) and TS-primary backends (Hex) are above current level.

## Gap and how to close
1. For "open to both" roles (Hex, LangChain), current JS/React exposure likely clears the bar - frame it directly.
2. For TS-primary roles (Vercel), either invest to close the gap or deprioritize.
3. A small TS/Next.js project (or porting an Agentic RAG UI piece) would raise this from learning to working.
