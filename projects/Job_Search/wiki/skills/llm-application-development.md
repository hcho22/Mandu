# LLM application development

## What it is
The general craft of building production applications on LLMs: prompting, context engineering, RAG, agents, tool use, and shipping/deploying at scale.
The umbrella competency under which [[rag-systems]], [[agent-orchestration]], and [[prompt-engineering]] sit.

## Why roles want it
The core of every AI-builder role ingested. Postings phrase it as "production experience building LLM-powered applications" (Anthropic) or "designed LLM-powered applications beyond simple API calls" (LangChain).

## How to acquire or demonstrate
Ship and operate a real LLM application end to end, not a demo.
Show the full lifecycle: prompting, context, retrieval, agents, evaluation, deployment.

## hcho's current level: strong
Evidence: Agentic RAG (production LLM app, framework-free), FitSnack (LLM "Variety Language" slice), CreativeBridge (multi-AI: GPT-4o-mini + Stable Diffusion + Claude Skills). Multiple shipped LLM apps across B2B and B2C.
This is a demonstrated core strength.

## Gap and how to close
Minimal skill gap; the work is packaging and legibility (public repos, clear architecture writeups).
