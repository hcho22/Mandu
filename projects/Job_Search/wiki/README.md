# Job-Search Roles Wiki

The front door for hcho's job-search knowledge base.
This wiki maps the roles hcho is targeting, the qualifications and skills each one demands, and the concrete path from his profile into that role.

- **Schema / operating manual:** [[CLAUDE]] - read it in full before touching this wiki.
- **Mode:** `full` (Claude writes and maintains every page; hcho reviews and steers).
- **Big picture:** start at [[synthesis]].
- **Catalog:** [[index]] lists every page.
- **Timeline:** [[log]] is the append-only event history.

## The three questions this wiki answers

1. **Roles** - what each target role (AI builder + AI evals / quality buckets) actually is and does.
2. **Requirements** - the qualifications, skills, and portfolio evidence each role wants.
3. **Path** - the gap between hcho's profile and each role, and how to close it fastest.

## How to use it

- Drop a source (a job posting, a role guide, a market report) into `../raw/` and say "ingest this."
- Ask questions against the wiki ("what's the gap for an evals role?", "which skill closes the most roles?").
- Ask for a periodic `lint` to keep it healthy.

Full workflow details for each operation are in [[CLAUDE]].
