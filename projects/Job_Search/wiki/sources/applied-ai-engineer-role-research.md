# Source: Applied AI Engineer - role research pull

Distilled research pass on the Applied AI Engineer / AI Engineer (product) role, July 2026.
Raw file: `raw/applied-ai-engineer-role-research-2026-07-08.md`.
Aggregated from Indeed, AI Shipping Labs (1,000+ JD analysis), DigitalApplied, AY Automate, and Coursera (see raw file for URLs).

## Key claims extracted

- The 2026 "AI Engineer (product)" role is the Applied AI Engineer: if 70%+ of the work is prompts, RAG, agents, and eval, it is this role.
- It is full-stack product work: backend orchestration, RAG, evals, some frontend, product instinct.
- Ship gate is now a baseline expectation: a versioned eval set, a numerical score, and a regression alarm; offline (~200 curated examples) plus online LLM-as-judge on production traces; track task-success, latency, cost-per-task.
- Recurring hard requirements: Python, LLM app dev (prompting/RAG/agents), vector DB + RAG architecture, a model provider, an orchestration framework (or deliberate framework-free), eval tooling, API integration, cloud deployment, SQL, MLOps.
- Comp signal: agentic AI engineer band ~$185K-$320K base + equity; RAG architecture +10-15%, fine-tuning +10-15%, MLOps +$15K-$30K vs notebook-only.
- Market signal: "LLM"/"RAG" postings up ~340% since 2024; generic "machine learning" postings down ~18%.
- Education: Bachelor's sufficient; Master's/certs are a plus, not a gate.
