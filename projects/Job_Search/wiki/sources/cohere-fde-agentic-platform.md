## Key claims / requirements (shared)
- Shipped lots of production-grade Python (clean, testable, observable, scalable).
- Built/deployed performant RAG and agentic applications, incl. agents that plan and execute multi-step tasks using patterns like **ReAct or Plan-and-Execute**.
- Deep familiarity with the LLM stack: frontier models, vector DBs, orchestration frameworks.
- Own the design, build, and deployment of LLM-powered agentic workflows end to end, from prototype to production; enterprise-high bar (reliable, observable, safe, auditable).
- Works across the stack; flexes into whatever the problem demands (including frontend, as a bonus not a gate).
- Customer-facing: translate ambiguous enterprise problems into concrete specs; own use cases end to end; 20-40% travel.

- **General / on-prem:** the deployment surface is private-cloud / on-prem for regulated clients - an infra / [[distributed-systems]] lean.
