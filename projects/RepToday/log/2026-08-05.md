## Notes / Learnings

- **Transport changed, and for a good reason.** The US-T01 spike was worth running: `convex-swift` builds against iOS 17 fine, but its xcframework is arm64-only (no x86_64 slice), so it would break every Simulator test suite on the Intel host. The adopted Convex-HTTP-action + `URLSession` transport keeps **zero new Swift Package dependencies** (Lottie stays the only one) - strictly better than the planned SDK add. My 2026-08-04 decision-log/priorities entries that named `convex-swift` as "the only new dep" are now wrong and were corrected today.
- **The whole foundation ships uncalled by design.** Seam (T02), sink (T03), identity (T05), and transport (T04) all landed, but nothing calls `record(_:)` yet. A build today carries a complete, inert pipeline. Emission starts at US-T07 (after US-T06's consent gate). This is deliberate dependency-first sequencing, not a gap.
- **Two small naming deltas from the PRD, documented in-repo:** the live container's inert placeholder is `NoOpAnalyticsService` (not the recorder `MockAnalyticsService`, which would grow unbounded in production); the protocol method is `record(_:) async`, deliberately not `throws`, because emission is fire-and-forget.
- **Release builds are inert:** the analytics endpoint is a per-configuration build setting (`REPTODAY_ANALYTICS_ENDPOINT`), Debug -> dev deployment, **Release -> nothing**, so choosing the production sink is now a precondition on US-T07.
