# Rep Today

**One-liner:** A discipline-first micro-workout iOS app. Open it and a complete zero-equipment session (5-60 min) is already waiting - a deterministic on-device engine blends strength, mobility, and primal movement to land within ±1 min of your Default Duration. No browsing, no choosing, no thinking. Between sessions a daily-adaptive AI Programmer quietly rewrites each user's Session Policy (progression, pillar weighting, variety); it shapes the program, never the workout, and is never on the path to pressing start.

## Why this project / how it fits

- **Income bet #1 (B2C):** a consumer subscription app is a different revenue shape and buyer from the Purvia kit, so it hedges the product path without competing for the same customer.
- **AI-builder portfolio asset:** demonstrates shipped, end-to-end product engineering - SwiftUI + Observation, MVVM with protocol-based DI, CoreData/CloudKit, StoreKit 2, Sign in with Apple, HealthKit, a production Convex telemetry path, and two bounded proxy routes. The deterministic AI Programmer rewrites Session Policy on-device; the premium `gpt-5.6-luna` Coach may talk and offer clamped policy changes but never generates or safety-checks a workout. The core engine remains offline and deterministic.
- **Validation / quality angle (the cross-cutting edge):** the on-device engine is fully deterministic (no network, no LLM, <100ms) and backed by a broad test matrix - engine session-shape/staleness/timing-fit, Consistency Score edge cases (single-miss dents but never zeroes, 5-min counts as a full show-up), PhaseEvaluator promotion rules, persistence round-trips. This is the same validation-rigor differentiator hcho leads with elsewhere, expressed in a consumer app.

## Monetization

Freemium, paywall on **depth** not the core loop (the discipline promise stays free forever):

- **Free tier:** unlimited workouts forever, the full 76-movement library, Consistency Score, weekly goal, basic history, and the earned Strength Phase. Never gated.
- **Premium ($7.99/month with a 2-week free trial, or $59.99/year with no trial, as App Store Connect served them to firstmate's sandbox probe on 2026-10-16; the trial offer was created that day, US):** the depth layer - full analytics and the optional AI Coach. Via StoreKit 2 (subscriptions, paywall, Restore Purchases).

## Product model

- **Two-phase journey:** every user starts in the **Discipline Phase**. The **Strength Phase** is earned by sustaining the habit and progressing the movement chains, never user-selectable or paywalled. Completion persists the transition; app-open reconciliation migrates already-qualified histories; once earned, Strength cannot be downgraded by a later stale save.
- **Consistency, not gamification:** no XP/levels/badges in the MVP. A rolling, weighted **Consistency Score** replaces the brittle streak; `longestChain` is surfaced as pride, never a threat; all copy is identity-framed ("you're someone who moves").
