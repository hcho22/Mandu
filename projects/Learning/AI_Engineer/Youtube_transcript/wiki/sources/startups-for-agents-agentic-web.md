# Startups for Agents: Building for the Agentic Web

A Startup Ideas Podcast primer arguing that the internet is shifting from human users to AI agents as the customer, and mapping the products, infrastructure, and startup opportunities that shift creates.
It covers the agent buying journey, what agents uniquely need, agent-readable websites, the move from SEO to AEO, and a rapid-fire list of agent startup ideas.

## Key claims

- For decades the end users of the internet were humans; increasingly AI agents are the customer. The forecast: over 10 years, billions of agent "customers" with millions of wallets, and almost every SaaS category rebuilt in agent-native form.
- The human customer wants persuasion; the agent customer wants structured capability, permission, and trust. The old web was humans searching/reading/clicking/buying; the agent web is agents discovering, evaluating, invoking tools, paying, and renewing.
- The agent buying journey has six stages: finding, evaluating, trust, transacting, using tools, and recommending - including the "weird" part where agents recommend tools to other agents.
- Agents need six building blocks: identity (who it acts for), tools (what it can safely invoke), inbox (where OTPs/docs/threads land), memory (preferences and rules), wallet (what it can spend and who approves), and receipts (what it saw, decided, changed, bought). Trust is granted like an employee: identity -> tools -> wallet.
- Concrete infrastructure already exists: AgentMail (email inbox API for agents, YC-backed), Stripe agent wallets (spend caps, approval rules, audit trail), and MCP servers so an agent uses declared tools instead of scraping the UI.
- A human homepage has brand/video/copy/social-proof/pricing; an agent-readable homepage exposes structured docs, schemas, policies, examples, endpoints - in practice MCP tools, SDKs, OAuth, checkout, a sandbox, and receipts, plus dedicated entry points like /agents. If an agent can't understand you or safely act, you are invisible to it.
- What changes for startups: SEO -> AEO (optimize for which agents cite/trust/recommend you), forms -> tool calls, support docs -> executable support, landing pages -> capability manifests, sales calls -> agent procurement, analytics -> agent analytics.
- Repeatable idea generator: take any popular tool and ask "what is the agent version of this?" (agent SEO agency, agent identity/permissions, agent receipts/audit trails, agent inbox security, MCP servers for franchises, sandbox for agents to test SaaS).
