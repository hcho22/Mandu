# 50 Things I'd Do If I Were Starting Over in My 20s or 30s

An opinion-heavy career talk (~50 tips in five themes) on building an irreplaceable tech career in the agentic-AI era.
The bulk is career strategy - mindset, money, health, networking, interviewing - which is out of this wiki's AI-engineering scope and belongs in `projects/job-search/interview-prep.md`.
Captured here are only the tips that inform this wiki's technical concepts: what holds value when code gets cheap (taste, agentic-tool mastery, knowing where AI fails), and the "agentic engineering as the new expertise" framing.

## Key claims

- Core thesis: code is becoming cheap, so durable value shifts to judgment, taste, domain ownership, and mastery of agentic tools; junior-level tasks automate first, so the rational hedge is to learn the tools deeply rather than flee them.
- "Taste is the moat": fully AI-generated writing/images/video is still usually obvious, so encoding your taste so the machine can reproduce your judgment is the central skill.
- "Agentic engineering is the new expertise," with four named pillars: context engineering, agentic validations, agentic tooling (building tools for the agent), and compound engineering.
- Learn where the AI fails: enough hands-on use builds a "second sense" for the capability boundary; the framing offered is that LLMs "only ever hallucinate" and the useful outputs are "useful hallucinations," so keep a log of where systems succeed and fail.
- Read the hard code, skip the trivial: to build agentic tools, learn the ReAct loop (reason -> decide on tool use -> act -> repeat until done) by reading open-source agents; let AI handle easily-verified boilerplate.
- Master the agentic tools to a craftsman standard (how the harness loads memory and manages context, plus slash commands, skills, sub-agents, agent teams, scheduling loops) - the speaker claims tool mastery alone can get you hired.
- "Demos lie; production tells the truth": cites an MIT figure of ~95% of enterprise GenAI efforts failing to show meaningful progress (flagged by the speaker as dated, pre-Opus-4.5), and names Claude Code and Codex as the tools that "survived in production."
- Build for the model of the future, not today's: build agentic apps assuming the next model generation, because building only for current models is easy to copy and limits your thinking (attributed to a Boris Cherny talk about Claude Code).
