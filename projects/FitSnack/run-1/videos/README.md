# Nonzero videos

Two videos, both rendered fully locally with free tooling (headless Chrome, macOS `say`, ffmpeg). No paid services, no stock assets, no network dependencies.

| File | What | Length | Spec |
|---|---|---|---|
| `launch/nonzero-launch.mp4` | Launch video: the four-beat brand argument | 40s | 1280x720, 12 fps, h264 + aac |
| `founder/nonzero-founder.mp4` | Founder video: the validation-engineer case for the product | 102s | 1280x720, 12 fps, h264 + aac |

Design docs: `launch-storyboard.md` (scene table) and `founder-script.md` (full script + voice-rule compliance).

## Pipeline (proven first in `spike/`)

1. Each video is a single deterministic HTML page (`launch/frame.html`, `founder/frame.html`).
   The whole timeline is a pure function `window.seek(ms)`: every visual state is computed from the millisecond, so renders are reproducible and any frame can be debugged in a normal browser.
2. `render-frames.sh <dir> <duration_ms> [fps]` drives headless Chrome (via `chrome-devtools-axi`): seek, screenshot, repeat. Launch = 480 frames, founder = 1224 frames.
3. Voiceover: macOS `say` (Samantha for launch, Reed for founder), one AIFF per segment; segment durations were measured with ffprobe FIRST and the scene timings locked to them.
4. Bed: an ambient pad generated by ffmpeg (lowpassed brown noise + faint 110 Hz sine, faded in/out). VO sits ~25 dB above it; peaks kept under -1.5 dB.
5. Mux: `ffmpeg -framerate 12 -i frames/f%04d.png -i audio/mix.wav -c:v libx264 -pix_fmt yuv420p -c:a aac`.

## Honesty notes

- The founder video's narration is a macOS text-to-speech scratch track and its end card says so verbatim: "Narration: macOS text-to-speech scratch track. A placeholder, not the founder's voice."
- The founder script makes only two personal claims (ten years in hardware validation; builds AI products now), both true from the resume. The category failure story uses the measured 3% D30 stat, not invented autobiography.
- The phone screens in both videos are real screenshots of the working Ready Screen prototype (`../site/prototype/`), captured with the demo-controls row hidden (`assets/ready-clean.png`).
- Every on-screen and spoken claim is covered by `../extras/claims-lint/claims-matrix.md`, and both frame pages pass the voice-contract linter (`node ../extras/claims-lint/lint.js`).

## Verification performed (2026-07-09)

- Both MP4s probed: correct duration, resolution, and stream layout.
- Frames extracted from the encoded MP4s (not the source PNGs) at 9+ timestamps each and visually inspected: scene sequencing, dent tick 96 to 94, slash drawing left-to-right and rising, captions, end cards, disclosure line.
- Audio verified with astats: VO regions ~-15 to -21 dB RMS vs pad-only regions ~-45 dB RMS; no clipping.
