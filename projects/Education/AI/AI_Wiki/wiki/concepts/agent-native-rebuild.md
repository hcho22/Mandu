# Agent-Native Rebuild ("what's the agent version of this?")

From [[startups-for-agents]]: the thesis that almost every existing SaaS category will be rebuilt in an agent-native form, and the single question that generates the opportunities - "what's the agent version of this?"

## Key points

- Take any popular tool (Notion, Slack, Stripe) and ask what a version built purely for agents would be: agent-native payments, communication, memory.
- The bet is that the machine-to-machine economy is early and under-built - billions of agent customers with millions of wallets over ~10 years - so most categories are open.
- The rapid-fire idea list (agent SEO agency, agent identity/permissions, agent receipts/audit trails, agent-ready docs generators, agent inbox security, MCP servers for franchises, agent support desk, SaaS sandbox for agents) all come from that one question.

## Synthesis

This is the generative engine of the [[agentic-web]] area: a reframing prompt, not a product.
It rhymes with [[agent-saas]]'s [[workflow-with-a-paycheck]] (find the automatable job) but points the other way - build the infrastructure the agent buys rather than the agent that does the job.
For hcho it is a portfolio-idea generator: the ideas with the most validation content (identity, permissions, receipts, audit trails, inbox security) are exactly where his edge applies, so the question doubles as a filter for which agent-native bets fit him.
