# OpenCode

An open-source agent coding harness, used as the main harness in [[building-products-with-agents]].

## What shows up in the wiki

- Preferred for the ability to quickly try new models as they ship (the stated benefit of open-source agent tools).
- Also cited in [[ai-era-50-career-tips]] as an open-source agent worth reading to learn how the [[react-loop]] is really built.

## Notes

One of several harnesses in the sources ([[claude-code]], Codex, [[open-claw]], [[devin]], OpenCode); the recurring theme is that the harness is swappable and the leverage is in skills, context, and validation, not the specific tool.
